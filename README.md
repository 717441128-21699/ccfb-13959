# 中药粉末显微鉴别系统（TCM Micro-ID）

纯前端运行的中药粉末显微特征自动识别与药材鉴别系统。显微照片导入后，自动在 **WebGL2 GPU 着色器**中完成分割、距离变换与分水岭分离，再由规则引擎测量棱角角度、纹孔密度、壁厚比等连续性状，与《中国药典》粉末显微特征表比对，给出最相似的药材、判定依据，并对两味药掺混样品给出掺伪提示。检验员可直接在图上改判、删除、新增标注，所有编辑带撤销/重做。

## 设计目标与验收线

| 指标 | 目标 | 度量方式 | 当前状态 |
| --- | --- | --- | --- |
| 结构识别准确率 | F1 ≥ 90% | 合成金标准图的 TP/FP/FN，按类别与微平均 | ⚠ 未达标，见下方“当前指标与差距” |
| 出结果速度 | 30 张 / 2 分钟 | 单张平均耗时 × 30 ≤ 120 s（评测台实时显示） | ✅ 无头软渲染约 57s/30 张，真机 GPU 更快 |
| 染色鲁棒性 | 换人/换光源不跑偏 | 4 套染色预设（浅、深、冷、标准）随机轮换评测 | ✅ 光密度归一化已实现，阈值对预设不敏感 |
| 掺伪识别 | 双峰/互斥特征可检出 | 1/3 评测样本为双药混合，统计检出率与误报率 | ⚠ 规则已实现，受上游分类准确率制约 |

## 当前指标与差距（诚实说明）

本仓库的工程骨架（GPU 管线、测量、知识库、匹配、UI、评测台、人工修正闭环）已完整跑通并有 21 项单元测试覆盖，但在当前合成评测集上**结构识别 F1 约 9%~14%，距离 90% 目标有本质差距**，不可在交付中夸大为达标。已定位的根因：

1. **重叠结构粘连是首要瓶颈**。合成图按“带重叠”生成时，交叉的纤维/导管/石细胞在分割后连成单个连通块，长宽比、圆度、壁厚等几何特征整体失真，规则分类随之失效；零重叠批次 F1 也仅约 14%，说明问题不止重叠。
2. **部分连续性状测量仍不够判别**。壁厚比依赖内腔/壁带灰度对比，纹孔密度在小目标上信噪比低，导致石细胞、纤维、晶纤维三类召回接近 0，是最大失分点。
3. **规则评分的类别覆盖不均衡**。导管/淀粉有一定召回（导管召回曾达 80%+、淀粉 50%+），但方晶等类易成为碎块兜底，产生大量误报。

后续把 F1 推向 90% 的建议路径（按性价比排序）：

- 用人工复核数据训练一个轻量分类头（MLP 或小型 CNN）直接消费现有 `MeasuredFeatures` 向量，替代手写软评分；测量与 GPU 分割层无需改动，可解释性由特征本身保留。
- 改进重叠分离：在分水岭之前加入基于轮廓凹点的切割，或对粘连连通块做骨架/方向分析，恢复单目标几何。
- 降低合成图默认重叠密度、并补充更贴近真实制片的染色填充，先在低难度集上把单类 F1 做高，再逐步加难度。
- 针对石细胞/纤维补强壁厚与纹孔的测量信噪比（更大尺度的壁带采样、形态学开运算估计内腔）。

评测台（左侧“运行 30 张评测”或 `npm run e2e`）会实时输出每类 P/R/F1、混淆矩阵、Top-1/Top-3、掺伪检出率与耗时，是后续迭代的量化仪表盘。

## 技术架构

```
图像输入 ──► GPU 片元着色器管线（GpuEngine, WebGL2 + 浮点纹理）
             染色归一化(光密度+百分位拉伸) → 盒式模糊/局部方差
             → Sobel → 自适应背景最大值滤波 → 阈值分割
             → 形态学开闭 → JFA 距离变换
CPU 后处理   填洞 → 连通域(并查集) → 距离峰种子
GPU 再处理   JFA 分水岭标记传播（分离重叠目标）
CPU 测量     图像矩/凸包/轮廓棱角/壁厚比/纹孔密度/纹理方向
规则分类     模糊评分 → 10 类结构 + 导管 5 种纹理亚型
药典匹配     丰度符合度 + 性状模糊区间符合度 → 药材排序与依据
掺伪分析     棱角/纹孔一维 k-means 双峰检验 + 互斥诊断特征共存
```

- `src/gpu/` — GLSL 着色器与 WebGL2 GPGPU 引擎（FBO 池、ping-pong、Jump Flooding）
- `src/core/` — 类型、知识库、几何/统计、连通域、测量、分类、匹配、评测
- `src/synthetic/` — 按药典形态参数程序化绘制的合成图生成器（金标准）
- `src/ui/` — 三栏工作台、画布叠加标注、编辑历史、评测台

## 合成测试图说明

生成器按知识库中的药典区间抽样形态参数，程序化绘制：草酸钙簇晶（棱角尖/钝参数化）、方晶、石细胞（壁厚、纹孔疏密、分枝）、五类纹理导管、纤维/晶纤维、淀粉粒（脐点/裂缝）、花粉粒，并叠加：

- **气泡**：亮空泡、强边缘、无内部纹理，分类器需排除而非计入；
- **重叠**：随机让若干目标部分重叠，靠距离变换 + 分水岭拆分为两个标注；
- **染色漂移**：4 套预设改变染色强度、色温、伽马与噪声，验证光密度归一化的不变性；
- **碎片干扰**：无诊断形态的不规则小颗粒。

每张图输出像素级金标准（类别、位置、形态参数），评测台据此计算指标。

## 关键鲁棒性设计

1. **染色不变量**：RGB 先转光密度 `-log(I)`，按全图百分位拉伸到归一区间，分类只依赖归一化灰度、饱和度残差与形态，不依赖绝对颜色。
2. **细微形态可分**：簇晶棱角（内角）、石细胞纹孔密度（壁带暗斑计数/周长）、导管纹理亚型（边缘方向与脊线密度）均为连续测量值，与药典区间做梯形模糊匹配，而不是硬阈值。
3. **掺伪**：同型结构的双峰分布（如锐尖簇晶与短钝簇晶）用一维 k-means 检验，配合互斥诊断特征共存与 Top-2 相似度接近三条证据联合判定。
4. **人工修正闭环**：图上改判/删除/新增均入栈可撤销，编辑后实时重算药材匹配与掺伪结论，可作为后续规则/模型迭代的复核样本。

## 边界与后续

- 当前识别为可解释的规则/模糊系统，适合药检场景的可追溯要求；积累足够人工复核数据后，可在同一 GPU 管线后接轻量 CNN 做分类残差校正，测量与匹配层无需改动。
- 真实显微照片接入后，建议先用评测台的参数滑杆校准阈值，再用合成+真实混合集复核 90% 指标；标尺 μm/px 需按显微镜标定值填写。
